# Beautiful Barometer

Мощный барометр для Android. Приложение показывает атмосферное давление с датчика в смартфоне, создает историю на красивом графике, показывает тенденции погоды и помогает понять, например, сколько метров высоты набрано в горном походе (без GPS и его погрешностей), когда лучше поехать на рыбалку или отложить все важные дела на другой день, если вы метеозависимы :)

[Скачать последнюю APK](https://github.com/gordeychernyshev/beautiful_barometer/releases/latest)

## Что умеет

- запись атмосферного давление в фоне;
- установка базовой высоты по GPS/вручную/по давлению;
- текущее давление, высота (дельта от базовой и над уровнем моря) и изменение за 3 и 24 часа;
- график давления и высоты за выбранный период с масштабированием;
- статистика периода: минимум, максимум, среднее, амплитуду, шум, самый быстрый рост и спад;
- локальный прогноз по тренду давления с оценкой качества данных;
- отображение событий на графике (технические и метеопредупреждения);
- режим поездки, чтобы не путать перепады высоты в метро с погодой;
- обычные и умные уведомления об изменениях давления;
- плитка быстрых настроек для включения и выключения записи;
- экспорт истории в CSV;
- светлая, тёмная и AMOLED-темы, следует за системной;
- логирование и отчёт если у вас прога таки упадёт :)

## Зачем это нужно

Обычное погодное приложение показывает прогноз по району, где давление - одна из самых незаметных для пользователя характеристик.
Мой барометр целиком и полностью реализует свой функционал используя только датчик давления в смартфоне и будет полезен, если вы:

- следите за перепадами атмосферного давления;
- хотите сделать свою домашнюю метеостанцию;
- планируете пойти на рыбалку;
- замечаете связь самочувствия с погодой;
- идете в горы где высоте по GPS нельзя доверять;
- тестируете смартфоны на влагозащиту;
- просто хотите найти применение датчику давления в смартфоне :)

## Требования

- Android 8.0 или новее;
- физический датчик атмосферного давления в смартфоне;
- разрешение на уведомления для постоянного фонового сервиса на новых версиях Android.

Если на устройстве нет барометра, приложение покажет предупреждение и не будет пытаться записывать несуществующие данные.

## Сборка из исходников

Всё написано на Java и собирается обычным Android Gradle Plugin.

Debug-сборка:

```bash
./gradlew assembleDebug
```

На Windows:

```powershell
.\gradlew.bat assembleDebug
```

Тесты:

```bash
./gradlew testDebugUnitTest
```

Release-сборка:

```bash
./gradlew assembleRelease
```

## Docker-сборка

В репозитории есть Dockerfile и docker-compose для воспроизводимой debug-сборки без ручной установки Android SDK.

```bash
docker compose run --rm barometer-builder
```

По умолчанию контейнер запускает:

```bash
./gradlew assembleDebug
```
